# 🪐 Hand-Controlled Solar System

## 📖 About The Project
This is an interactive software project that allows users to explore and control a simulation of the solar system using hand gestures. It provides a unique, hands-free way to interact with virtual planets.

## ✨ Features
* **Gesture Control:** Navigate and interact with the solar system planets using simple hand movements.
* **Interactive Interface:** A clear and responsive visual representation of the solar system.
